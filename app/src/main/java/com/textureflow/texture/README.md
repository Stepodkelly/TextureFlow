# `texture/` — sensory cues (sound + haptic)

Not the UI layout — the **feel** of events (proposal ready, success, failure…).

| Important file | Role |
|----------------|------|
| `TextureCue.java` | Named cues |
| `TextureCueScheduler.java` | When to play cues |
| `TextureHapticRenderer.java` | Vibration patterns |
| `TextureAudioRenderer.java` | Short audio cues |
| `SensoryProfile.java` | User sensitivity profile |
